# Frostline

AI that reads road conditions (snow, ice risk) from traffic cameras that transportation departments already own.
Capital Hacks 5.0, team The Vibe Stack.

```
python -m pip install -r requirements.txt
python frostline.py                  # analyze all cameras (add --no-clip for a fast run)
python -m streamlit run dashboard.py # demo screen
```

Builders: start with `CLAUDE.md`, then your file in `builders/`. Plan: `PLAN.md`.
